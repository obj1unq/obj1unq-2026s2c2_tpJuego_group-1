# La Isla

En una isla lejana y aislada de todo, el protagonista sufre un accidente que lo deja varado y sin posibilidad de regresar.

Ahora deberá sobrevivir, explorar la isla y encontrar una forma de escapar, mientras se enfrenta a los peligros que acechan en cada rincón.
